    between

    • between(before: IDigits, after: IDigits, round: boolean): IDigits

      Gets the mid position for any number with the equation q = (nf + n0) / 2, where:

      • n0 represents the start string converted from the nth base to the 10th base
      • n1 represents the end string converted from the nth base to the 10th base

      Parameters

      • before: IDigits

        In the evaluation of two strings n1 &lt; n2 must be n1

      • after: IDigits

        In the evaluation of two strings n1 &lt; n2 must be n2

      • round: boolean

        Rounds the result to the nearest upper integer if set to true

      Returns IDigits

      The value q - ( q mod 2 ) When q mod 2 is different from 0 then the mid character from the set of the nth base, should be placed at the end of the output.

    diverge

    • diverge(value1: IDigits, value2: IDigits): IDigits

      This system function will equalize the length of value1 and value2 adding zeroes to the right of the shorter number if needed, then will find the point where CharacterBefore &lt;&gt; CharacterAfter. Upon the room between these:

      • If the room > 1 will only find the value between them
      • If room <= 1 will use and optimized version of the Between function

      Params

      Parameters

      • value1: IDigits

        Must be any value such that value1 &lt; value2 or value2 &lt; value1

      • value2: IDigits
