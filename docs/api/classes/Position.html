    Class Position

    The default class of the positions: data plus the comparison functions.

    You never create positions with new: a Staquia system creates them (forge, start, next, previous, core) as instances of its own subclass of this class (or of the class passed in its options), so position instanceof Position is true. Extend it to add your own methods to every position, see IStaquiaOptions.

    Example

    import Staquia, { Position } from "staquia";

    const system = Staquia.create("!", "a", "z", 5, 15, 0.15);

    const start = system.start();
    if (start.ok) {
      console.log(start.value instanceof Position); // true
      console.log(start.value.toString()); // "mmmmm!"
    }

    length

    length: number

    The length measured when the position was created (N plus Z), the one the threshold and the max length are compared with. It doesn't count the zeroes that complete the string: "mmmmm!" created by start has 5, "ab!!!!" forged from "ab" has 2.

    compare

    • compare(other: IPosition): Ordering

      Compares this with other, like a sort comparator.

      Parameters

      • other: IPosition

        The object to compare with.

      Returns Ordering

      "less" if this goes before other, "equal" if they have the same value, "greater" if it goes after.

      Example

      import Staquia from "staquia";

      const system = Staquia.create("!", "a", "z", 5, 15, 0.15);
      const a = system.forge("mmmmm!m");
      const b = system.forge("mmmmn");

      if (a.ok && b.ok) console.log(a.value.compare(b.value)); // "less"
