    Class LexicalError

    Returned (never thrown) when a LexicalList operation fails; its type tells why. When an operation returns an error, neither the list nor your objects were changed.

    Example

    import Staquia, { LexicalList } from "staquia";

    const list = new LexicalList(Staquia.create("!", "a", "z", 5, 15, 0.15));

    const result = list.move(9, 1, 2);
    if (!result.ok) console.log(result.error.type); // "not-found"
