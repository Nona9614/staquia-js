    Class Digits

    The default class of the numbers: the digits of a number in the base of a system, stored by key. The key is the power of the base, so a higher key is a more significant digit: the base 10 number 123 is 1 at the key 2, 2 at the key 1 and 3 at the key 0. Negative keys are the digits after the point.

    The systems create and initialize their numbers, you get them from a position with digits(). Extend it to replace the numbers of a system, see IStaquiaOptions.

    Example

    import Staquia from "staquia";

    const system = Staquia.create("!", "a", "z", 5, 15, 0.15);

    const next = system.next(system.start()); // "mmmmn!"
    if (next.ok) {
      const digits = next.value.digits();
      console.log(digits.upperBound, digits.lowerBound); // 4 -1
      console.log(digits.get(4), digits.get(0)); // 13 14, "m" and "n"
    }

    Type Declaration

      • (this: IDigits, other: IDigits): Ordering

      • Parameters

        • this: IDigits
        • other: IDigits

          The object to compare with.

        Returns Ordering

        "less" if this goes before other, "equal" if they have the same value, "greater" if it goes after.

    Example

    import Staquia from "staquia";

    const system = Staquia.create("!", "a", "z", 5, 15, 0.15);
    const a = system.forge("mmmmm!m");
    const b = system.forge("mmmmn");

    if (a.ok && b.ok) console.log(a.value.compare(b.value)); // "less"
