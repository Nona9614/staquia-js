    Class Staquia

    A lexicographic number system that creates positions: short strings that keep the order of a list. Sort the items by their position string and you get the order back; moving an item only changes its own position.

    Create one with Staquia.create (or Staquia.default), then use it to create positions, or give it to a LexicalList to keep the positions of your objects in sync. Nothing is thrown: every function that can fail returns a Result.

    Example

    import Staquia from "staquia";

    const system = Staquia.create("!", "a", "z", 5, 15, 0.15);

    const start = system.start(); // "mmmmm!"
    const next = system.next(start); // "mmmmn!", stacked after start
    const core = system.core(start, next); // "mmmmmn", between both

    if (core.ok) console.log(core.value.toString()); // "mmmmmn"

    Remarks

    Read the guide at the Staquia documentation page.

          next: IPosition | IPositionResult,

      Creates a position between two others, to move or insert an item between its neighbors.

      The room left in the N section is used first. When the positions are adjacent, the Z section takes the middle value, making the position one digit longer. Moving items again and again into the same gap makes positions grow until the threshold (ThresholdReachedError) and the overflow (OverflowError).

      Parameters

      • previous: IPosition | IPositionResult

        The position that must be before the new one (or a result with it).

        The position that must be after the new one (or a result with it).

      Returns IPositionResult

      The position between previous and next, or the error (including a SystemMismatchError if a position was created by a system with another configuration).

    Staticcreate

    • create(
          zero: string,
          first: string,
          last: string,
          ln: number,
          lz: number,
          fϰ: number,
          options?: IStaquiaOptions,
      ): Staquia

      Creates a number system. Its digits are the zero and every character from first to last, so its base is b = (last - first) + 2 (by their unicode values).

      Use characters of the Basic Multilingual Plane (up to U+FFFF), so JavaScript, UTF-8 and UTF-16 compare them in the same order. The characters must be zero < first < last.

      Parameters

      • zero: string

        The character of the zero digit.

      • first: string

        The character of the first digit (1).

      • last: string

        The character of the last digit (b - 1).

      • ln: number

        The fixed length of the N section, used to stack items without making positions longer.

      • lz: number

        The max length of the Z section, used when items are moved between two others.

      • fϰ: number

        A factor from 0 to 1: the threshold is reached at the length lϰ = ceil((1 - fϰ) * (ln + lz)).

      • Optionaloptions: IStaquiaOptions

        Replaces the classes used to create positions and numbers, see IStaquiaOptions.

      Returns Staquia

      The Staquia system.

      Example

      import Staquia from "staquia";

      // The alphabet: "!" is 0, "a" is 1 and "z" is 26, a base 27 system
      const alphabet = Staquia.create("!", "a", "z", 5, 15, 0.15);

      const start = alphabet.start();
      if (start.ok) console.log(start.value.toString()); // "mmmmm!"

          ln: number,
          lz: number,
          fϰ: number,
          options?: IStaquiaOptions,
      ): Staquia

      Creates a number system from a set of characters: the zero followed by every digit, sorted by their code, so its base is the number of characters. Use it when the digits are not a range, for example to leave some characters out; a set whose digits are consecutive is the same system as create with that range, and their positions are compatible.

      The characters must be sorted by their code without repeating any, and be in the Basic Multilingual Plane (up to U+FFFF), so JavaScript, UTF-8 and UTF-16 compare them in the same order.

      Parameters

      • characters: string

        The zero followed by every digit, sorted by their code.

      • ln: number

        The fixed length of the N section.

      • lz: number

        The max length of the Z section.

      • fϰ: number

        A factor from 0 to 1: the threshold is reached at the length lϰ = ceil((1 - fϰ) * (ln + lz)).

      • Optionaloptions: IStaquiaOptions

        Replaces the classes used to create positions and numbers, see IStaquiaOptions.

      Returns Staquia

      Example

      import Staquia from "staquia";

      // The digits without the vowels: "0" is the zero
      const system = Staquia.fromCharacters("0bcdfghjklmnpqrstvwxyz", 5, 15, 0.15);
